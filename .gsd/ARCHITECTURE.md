## Data Flow

1. **User Action / Telemetry Ingestion:** Wearable sensors (HealthKit/BLE) or user actions emit data into local Zustand stores.
2. **Deterministic Processing:** Domain engines calculate immediate feedback (e.g. readiness adjustment, rest countdown).
3. **Optimistic Local Persistence:** State is written instantly to `localStorage` / `IndexedDB` with pending sync tags.
4. **Outbox Synchronization:** Background sync workers push queued mutations to Supabase PostgreSQL over authenticated TLS.
5. **Real-time Synchronization:** Supabase Realtime channels broadcast updates across sessions and trainer dashboards.
